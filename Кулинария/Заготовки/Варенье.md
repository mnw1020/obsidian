1000 г ягод
250 г сахара
8 г NH-пектина
1 г ксантана
1 г соли

Пектин смешать с сахаром.
Нагреть ягоды до 45°C., всыпать сахар помешивая. Довести до кипения, добавить соль, варить 1 минуту. Сесть с огня и добавить ксантан (смешанный с ложкой сахара чтобы комков не было)

Специи варить в марле, после вынуть.

МАЛИНА 🍓

1. Базилик + лимонная цедра
   - свежий, ресторанный вкус

2. Мята + лайм/лимон
   - летний, освежающий

3. Ваниль + розовый перец
   - десертный, сложный аромат

4. Тимьян + лимон
   - благородный травяной вкус

5. Лаванда (очень мало) + лимон
   - французский цветочный стиль


ЧЁРНАЯ СМОРОДИНА 🫐

1. Бадьян + лимонная цедра + розовый перец
   - глубокий, пряный, лучший вариант

2. Мята + лайм
   - свежесть, подчёркивает ягоду

3. Тимьян + лимон
   - лесной, сложный вкус

4. Имбирь + апельсиновая цедра
   - яркий, согревающий

5. Можжевельник + розмарин (очень мало)
   - хвойно-ягодный аромат


ВИШНЯ 🍒

1. Бадьян + апельсиновая цедра
   - лучший баланс

2. Ваниль + тёмный шоколад
   - классика "Чёрного леса"

3. Амаретто/миндаль + ваниль
   - идеальное сочетание с вишней

4. Кардамон + лимонная цедра
   - восточный аромат

5. Тимьян + чёрный перец
   - гастрономический вариант


ДОПОЛНИТЕЛЬНЫЕ УДАЧНЫЕ СОЧЕТАНИЯ

Малина:
- Розовый перец
- Имбирь + лимон
- Ваниль + базилик

Чёрная смородина:
- Апельсиновая цедра + корица
- Бадьян + мята
- Имбирь + мёд

Вишня:
- Корица + ваниль
- Шоколад + апельсин
- Розмарин + лимон


МОИ ЛУЧШИЕ 5:
