# 📊 Итоги чтения

[[Книги/_index|← Библиотека]] · [[Книги/_system/Идеи и цитаты|Идеи и цитаты]] · [[Книги/_system/Проверка библиотеки|Проверка библиотеки]]

Каждое чтение считается по истории внутри карточки, включая перечитывания. Любимые произведения — художественные с последней оценкой 8–10. Если у даты известен только месяц, он сохраняет эту точность.

```dataviewjs
const file = app.vault.getAbstractFileByPath("Книги/_system/reading_dashboard.js");
if (file) {
    const m = { exports: {} };
    new Function("module", await app.vault.read(file))(m);
    await m.exports({ dv, app, obsidian: typeof require === "function" ? require("obsidian") : {}, mode: "index" });
}
```
