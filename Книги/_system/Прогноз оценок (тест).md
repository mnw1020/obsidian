# Прогноз оценок — тест

[[Книги/_index|← Библиотека]]

Экспериментальная таблица только для художественных произведений. Живая версия пересчитывается по текущим оценкам. Ниже — сохранённый снимок первоначального расчёта.

Сравниваются модели по автору, типу произведения и серии, а также простые общие ориентиры. Для произведений без оценки первоначальная проверка выбрала модель по типу. Заметки, отзывы, цитаты, число перечитываний и собственная оценка прогнозируемой книги не используются. Для оценённых книг собственная оценка исключена также из выбора модели. Это ретроспективная проверка на остальных книгах, включая прочитанные позже; историческим прогнозом до чтения она не является. У проверочных строк разные обучающие наборы, поэтому прогнозы могут различаться даже при одинаковых признаках.

Без оценок автора и серии прогноз приблизительный. «Без оценки» не означает «не прочитано». Если доступные признаки совпадают, одинаковые прогнозы ожидаемы.
