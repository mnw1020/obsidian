# 💡 Идеи и цитаты

[[Книги/_index|← Библиотека]] · [[Книги/_system/Итоги чтения|Итоги чтения]] · [Добавить выписку](obsidian://quickadd?choice=%D0%9A%D0%BD%D0%B8%D0%B3%D0%B8%20-%20%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C%20%D0%B2%D1%8B%D0%BF%D0%B8%D1%81%D0%BA%D1%83)

Выписки хранятся внутри книги. Здесь можно искать по тексту, темам, автору и типу, а ссылка под выпиской открывает её место в конспекте.

```dataviewjs
const file = app.vault.getAbstractFileByPath("Книги/_system/knowledge.js");
if (file) {
    const m = { exports: {} };
    new Function("module", await app.vault.read(file))(m);
    await m.exports({ dv, app, obsidian: typeof require === "function" ? require("obsidian") : {}, mode: "index" });
}
```

## Как включить старый конспект

Открой книгу в редакторе, выдели полный абзац или несколько целых строк и выбери «Добавить выписку» → «Оформить выделенный фрагмент конспекта». Проверь текст, выбери цитату или идею, добавь темы и свой вывод. Каждый фрагмент включается явно; остальные заметки остаются на своём месте.

Темы можно менять прямо в выписке. Пиши их через точку с запятой. «Место в источнике» — страница, глава или время аудиозаписи. Личный вывод необязателен.

Старые цитаты без специального идентификатора не входят в этот индекс, пока ты их не оформишь.

<summary>Пример выписки внутри книги</summary>

```markdown
> [!idea] Идея
> Текст мысли своими словами.
>
> <!-- BOOK-EXCERPT:META -->
> **Темы:** мышление; привычки
> **Вывод:** Попробовать применить эту мысль на практике.
> **Место в источнике:** глава 2, страница 17

^book-excerpt-example
```

Для цитаты используется `[!quote]`. При добавлении идентификатор создаётся автоматически; сохрани его, когда редактируешь текст, чтобы ссылки продолжали работать.
