# Настройка книжной базы

## Что уже сделано

- 1 книга = 1 карточка в `Книги/Карточки`.
- 1 факт чтения или перечитывания = 1 отдельная запись в `Книги/Чтения`.
- Старые дата и оценка перенесены в исходную запись чтения каждой книги.
- Старые отзывы и большие конспекты оставлены в карточках книг.
- Серии вынесены в `Книги/Серии`.
- Dataview для книжной базы больше не нужен.
- `Книги.base`, `Чтения.base` и `Серии.base` используют штатный Obsidian Bases.

## Один раз настроить Templater

1. Включи core plugin `Bases`.
2. Установи community plugin `Templater`.
3. Settings -> Templater -> `Template folder location`: `Книги/_system/Шаблоны`.
4. Включи `Trigger Templater on new file creation`.
5. `Template matching mode` -> `Folder templates`.
6. Добавь правило: `Книги/Карточки` -> `Книги/_system/Шаблоны/Книга.md`.
7. Добавь правило: `Книги/Чтения` -> `Книги/_system/Шаблоны/Чтение.md`.
8. Рекомендую включить Obsidian -> Files and links -> `Automatically update internal links`.

## ➕ Как добавить книгу

1. Открой `Книги/00 - Книги.md`.
2. В таблице `Все` нажми `+ New`. Это штатная кнопка Bases.
3. Templater спросит название, автора, тип, статус и при необходимости серию.
4. Файл автоматически получит имя `Автор - Название.md` и останется в `Книги/Карточки`.
5. Если книга уже прочитана, открой ее карточку и сразу создай запись чтения по инструкции ниже.

## 🔁 Как отметить перечитывание

1. Открой карточку книги.
2. Внизу есть раздел `Чтения и переоценки` со встроенной базой.
3. Нажми `+ New` прямо в этой базе.
4. Введи дату и новую оценку.
5. Создастся новая запись в `Книги/Чтения`; предыдущая запись останется нетронутой.
6. В карточке автоматически обновятся `last_read`, `rating` и `read_count`.
7. В созданной записи можно написать новое впечатление.

## Почему это не Git-версии

Перечитывание - это не исправление старой записи, а новое событие. Поэтому история хранится отдельными файлами чтений. Например:

- 2022-04-10 - 8/10 - старое впечатление;
- 2026-09-15 - 6/10 - новое впечатление.

Обе записи существуют одновременно. Никакой откат версии для этого не нужен. Для защиты от случайного удаления или неудачной правки можно отдельно пользоваться встроенным `File recovery` Obsidian или резервным копированием хранилища.

## Значения свойств

`category`:
- `fiction` - художественная;
- `nonfiction` - non-fiction.

`status`:
- `want` - хочу прочитать;
- `reading` - читаю;
- `read` - прочитано;
- `dropped` - брошено.

## Важное правило

Не меняй старую запись чтения, когда перечитал книгу. Создавай новую через `+ New`. Тогда история оценок и впечатлений сохраняется автоматически.
