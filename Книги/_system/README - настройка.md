# Настройка книжной базы

## Что изменено

- Исходные папки `Non-fiction`, `Художественные` и все существующие подпапки сохранены.
- Существующие книги не перенесены и не переименованы.
- В Base название книги является ссылкой на саму книгу.
- Автор в Base является ссылкой на страницу автора.
- На странице автора автоматически показываются все его книги, сгруппированные по сериям.
- Отдельных файлов и папки `Серии` нет.
- Свойства `status`, "хочу прочитать", "читаю", "брошено" не используются.
- Каждое перечитывание хранится отдельной записью в `Книги/Чтения`, поэтому старая оценка не уничтожается.

## Один раз настроить Templater

1. Включить core plugin `Bases`.
2. Установить community plugin `Templater`.
3. Settings -> Templater -> `Template folder location`: `Книги/_system/Шаблоны`.
4. Включить `Trigger Templater on new file creation`.
5. `Template matching mode` -> `Folder templates`.
6. Добавить правило:
   `Книги/_system/Новая книга` -> `Книги/_system/Шаблоны/Книга.md`.
7. Добавить правило:
   `Книги/Чтения` -> `Книги/_system/Шаблоны/Чтение.md`.
8. Рекомендуется включить `Files and links -> Automatically update internal links`.

## Добавить книгу

Открыть `Книги/00 - Книги.md` и нажать `+ New` в блоке "Добавить книгу".

Мастер спросит:
- название;
- автора или авторов;
- `Художественная` / `Non-fiction`;
- серию и номер, если есть;
- дату чтения и оценку, если книга уже прочитана.

Если у автора уже есть отдельная подпапка, новая книга автоматически попадет туда. Если его книги лежат прямо в разделе, новый файл останется там же.

## Перечитать книгу

1. Открыть саму книгу.
2. Внизу найти `История чтений`.
3. Нажать `+ New`.
4. Ввести новую дату и оценку.
5. Новая запись будет создана отдельно, старая останется без изменений.

Текущие `date` и `rating` в карточке книги обновляются на последние введенные значения.

## История и резервирование

Для перечитываний отдельный Git-контроль версий не нужен: каждое чтение является отдельной записью.

Для защиты от случайного удаления или неудачной правки рекомендуется отдельно использовать Obsidian File Recovery или обычную резервную копию vault.
