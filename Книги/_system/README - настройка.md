# Настройка книжной базы

## QuickAdd

Создай пять Choice типа `Macro` и добавь в каждый соответствующий `User Script`:

1. `Книги - Добавить книгу` -> `Книги/_system/QuickAdd/add_book.js`
2. `Книги - Добавить чтение` -> `Книги/_system/QuickAdd/add_reading.js`
3. `Книги - Редактировать чтение` -> `Книги/_system/QuickAdd/edit_reading.js`
4. `Книги - Открыть автора` -> `Книги/_system/QuickAdd/open_author.js`
5. `Книги - Открыть серию` -> `Книги/_system/QuickAdd/open_series.js`

У первых трех Choice включи молнию, чтобы команды были доступны как `QuickAdd: ...` для кнопок.
Для `Открыть автора` и `Открыть серию` молнию тоже можно включить. Основной вызов этих двух команд идет по ссылкам из Bases.

## История чтений

Отдельной папки `Книги/Чтения` больше нет.

В YAML книги хранятся только актуальные агрегаты:

```yaml
date: "2026-09-16"
rating: 8
read_count: 2
```

Для Non-fiction свойство `rating` не используется.

Подробная история находится в конце самой книги, внутри секции `## История чтений`.
QuickAdd управляет только текстом между служебными маркерами:

```text
<!-- BOOK-READINGS:START -->
...
<!-- BOOK-READINGS:END -->
```

Остальной текст книги, конспект, картинки и заметки скрипты не изменяют.

`Добавить чтение`:

- берет открытую книгу либо предлагает выбрать книгу;
- определяет следующий номер чтения;
- спрашивает дату, а для художественной книги еще оценку;
- спрашивает комментарий;
- добавляет новую запись непосредственно в карточку книги **после предыдущих чтений**;
- история всегда идет по возрастанию: `Чтение 1`, ниже `Чтение 2`, затем `Чтение 3` и т.д.;
- пересчитывает `date`, `rating` и `read_count`.

`Редактировать чтение`:

- берет открытую книгу либо предлагает выбрать книгу;
- показывает все ее чтения;
- позволяет изменить дату, оценку и комментарий;
- заново пересчитывает агрегаты книги.

Старые неполные даты `YYYY-MM` и `YYYY` поддерживаются и при редактировании сохраняются.

## Авторы и серии

Отдельных страниц для каждого автора и каждой серии нет.

В YAML книги хранятся обычные данные:

```yaml
authors:
  - "Олдос Хаксли"
series: "Название серии"
series_index: 2
```

В таблицах `Книги.base` колонки `Автор` и `Серия` являются вычисляемыми ссылками.
При клике они вызывают QuickAdd через `obsidian://quickadd` и передают выбранное имя.

QuickAdd переиспользует две служебные страницы:

- `Книги/_system/Автор.md`
- `Книги/_system/Серия.md`

`Автор.md` показывает все книги выбранного автора и группирует их по сериям.
`Серия.md` показывает книги выбранной серии по порядку и с кликабельными авторами.

Новые авторы и серии не требуют создания дополнительных Markdown-файлов.

## Перечитывания в общей базе

В `Книги.base` есть view `Перечитанные` с фильтром `read_count > 1`.
Одна строка там всегда соответствует одной книге. Подробная история открывается внутри самой книги.

## Убрать штатную кнопку New из книжных Bases

В архиве есть файл:

`.obsidian/snippets/books-bases-no-new.css`

Если распаковываешь архив прямо в корень vault, он сразу окажется в нужной папке. Затем:

`Settings -> Appearance -> CSS snippets -> Reload snippets`

и включи `books-bases-no-new`.

Сниппет скрывает кнопку создания только у книжных таблиц, помеченных `|no-new`. На другие Bases в vault он не влияет.

## Структура данных

Свойства `kind` и `status` не используются.

Книга определяется по расположению в `Книги/Художественные` или `Книги/Non-fiction` и наличию `title` + `authors`.
История чтений является частью Markdown самой книги и отдельной сущностью в файловой системе не является.

## Как теперь устроены серии

Пустые свойства `series:` и `series_index:` у одиночных книг удалены. Они появляются только у книг, которые реально отнесены к серии.

В `Книги.base` добавлен view `Серии`: все книги с серией сгруппированы по названию серии и отсортированы по `series_index`.

При добавлении новой книги QuickAdd больше не просит вводить название существующей серии вручную:

- после ввода автора показывает уже известные серии этого автора;
- можно выбрать `Без серии`;
- можно выбрать существующую серию;
- можно создать `➕ Новая серия`;
- для выбранной серии предлагается следующий номер, который можно изменить вручную.

Если команда запускается со служебной страницы серии, серия уже выбрана, а следующий номер предлагается автоматически.

На служебной странице `Серия.md` есть QuickAdd-кнопка `➕ Добавить книгу в серию`.
