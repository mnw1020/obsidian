# Настройка книжной базы

## QuickAdd

Создай пять Choice типа `Macro` и добавь в каждый соответствующий `User Script`:

1. `Книги - Добавить книгу` -> `Книги/_system/QuickAdd/add_book.js`
2. `Книги - Добавить чтение` -> `Книги/_system/QuickAdd/add_reading.js`
3. `Книги - Редактировать чтение` -> `Книги/_system/QuickAdd/edit_reading.js`
4. `Книги - Открыть автора` -> `Книги/_system/QuickAdd/open_author.js`
5. `Книги - Открыть серию` -> `Книги/_system/QuickAdd/open_series.js`

У первых трех Choice включи молнию, чтобы команды были доступны как `QuickAdd: ...` для кнопок.
Для `Открыть автора` и `Открыть серию` молнию тоже можно включить: тогда их можно запускать вручную из Command Palette, но основная работа идет по ссылкам из Bases.

## Как теперь работают авторы и серии

Отдельных страниц для каждого автора и каждой серии нет.

В YAML книги хранятся только данные:

```yaml
authors:
  - "Олдос Хаксли"
series: "Название серии"
```

В таблицах `Книги.base` колонки `Автор` и `Серия` являются вычисляемыми ссылками.
При клике они вызывают QuickAdd через `obsidian://quickadd` и передают выбранное имя.

QuickAdd переиспользует две служебные страницы:

- `Книги/_system/Автор.md`
- `Книги/_system/Серия.md`

`Автор.md` показывает все книги выбранного автора и группирует их по сериям.
`Серия.md` показывает все книги выбранной серии по порядку и с кликабельными авторами.

Новые авторы и серии не требуют создания дополнительных Markdown-файлов.

## Убрать штатную кнопку New из книжных Bases

В архиве есть файл:

`.obsidian/snippets/books-bases-no-new.css`

Если распаковываешь архив прямо в корень vault, он сразу окажется в нужной папке. Затем:

`Settings -> Appearance -> CSS snippets -> Reload snippets`

и включи `books-bases-no-new`.

Сниппет скрывает кнопку создания только у книжных таблиц, помеченных `|no-new`. На другие Bases в vault он не влияет.

## Структура данных

Свойство `kind` не используется.

Книга определяется по расположению в `Книги/Художественные` или `Книги/Non-fiction` и наличию `title` + `authors`.

Чтение определяется по папке `Книги/Чтения` и тегу `reading`.
