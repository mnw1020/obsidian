# Рекомендации

> [!info] Как работает
> Нажми **"🔎 Найти похожие"** в карточке фильма или сериала. Страница использует твою локальную модель, MovieLens и интернет-рекомендации IMDb. Для лучших кандидатов также пытается подтянуть карточку Кинопоиска через тот же публичный источник, который используется при добавлении фильма.
>
> - **Оценка 1-4**: ищутся альтернативы на ту же тему с более высоким персональным прогнозом.
> - **Оценка 6-10**: ищутся максимально близкие по теме фильмы, которые модель считает перспективными.
> - **Оценка 5**: нейтральный режим - баланс темы и персонального прогноза.
>
> Уже оцененные тобой произведения исключаются. В выдаче - до **20** рекомендаций.

function pearsonCommon(userMap,pairs) {

    for(let i=0;i<n;i++){const dx=xs[i]-mx,dy=ys[i]-my;nu+=dx*dy;vx+=dx*dx;vy+=dy*dy;}

}
