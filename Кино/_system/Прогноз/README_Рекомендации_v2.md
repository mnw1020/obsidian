# Рекомендации v2

Исправление страницы рекомендаций.

Главное изменение: интернет IMDb больше не блокирует построение страницы. Сначала выдаются рекомендации из MovieLens, затем IMDb добавляется как необязательный сигнал с жестким таймаутом.

Для точного фильтра по теме один раз запусти `Обновить каталог рекомендаций.bat`. Он не перестраивает 32 млн оценок, а только добавляет в уже готовый `movielens_neighbors.json` названия, годы и жанры из локального `ml-32m.zip`.

После этого кнопка `🔎 Найти похожие` во всех карточках продолжает работать как раньше.
