# Рекомендации по референсному фильму

Добавлено:

- кнопка **🔎 Найти похожие** во все текущие карточки;
- та же кнопка автоматически добавляется в новые карточки через `Examples_Attachments_movies.js`;
- динамическая страница `_system/рекомендации.md`;
- служебное состояние `_system/Прогноз/рекомендации_state.json`.

Логика:

- оценка 1-4 -> альтернативы на ту же тему, приоритет высокому личному прогнозу;
- оценка 6-10 -> похожие по теме, которые должны понравиться;
- оценка 5 -> нейтральный режим;
- до 20 результатов;
- уже оцененные произведения исключаются;
- используются локальная интерполяция, MovieLens, IMDb `moreLikeThisTitles`, а для финального списка выполняется попытка сопоставления с Кинопоиском через `movie-planner.ru`.

Никакой отдельной команды QuickAdd для кнопки не требуется: кнопка сама записывает выбранный референс в state-файл и открывает динамическую страницу.
