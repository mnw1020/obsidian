## 3. Базовый прогноз

По **1552 карточкам**, имеющим твою оценку и хотя бы один публичный рейтинг, подбирается линейная зависимость:

```text
личная оценка ≈ a + b × публичное среднее
b = Σ((public − среднее public) × (личная − средняя личная))
    / Σ((public − среднее public)²)
a = средняя личная − b × среднее public
```

Текущие коэффициенты: **a = -0,8891449924, b = 1,0556439805**.

```text
База «Новокаина» = −0,8891449924 + 1,0556439805 × 6,45
                 = 5,9197586817
```

То есть при публичном среднем 6,45 твоя типичная оценка по общей зависимости — около 5,92.

Наклон b ограничивается диапазоном −0,25…1,35, база — диапазоном 1…10. Если публичных пар меньше 20, база становится средней личной оценкой, b = 0. В текущем расчёте эти запасные случаи не понадобились.

## 4. Как сравниваются фильмы

Похожесть = сумма произведений коэффициентов на сходство признаков, делённая на сумму участвующих коэффициентов.

| Признак | Коэффициент | Сходство |
|---|---:|---|
| Описание | 0,25 | Косинус векторов TF-IDF |
| Жанры | 0,19 | Общих / √(число жанров A × число жанров B) |
| Актёры | 0,15 | Общих / √(число актёров A × число актёров B) |
| Режиссёры | 0,13 | Общих / √(число режиссёров A × число режиссёров B) |
| Публичное среднее | 0,10 | 1 − абсолютная разница / 7; ограничение 0…1 |
| Год | 0,05 | exp(−абсолютная разница лет / 11) |
| Тип | 0,045 | 1 при совпадении, иначе 0 |
| Длительность | 0,035 | exp(−абсолютная разница минут / 45) |
| Франшиза | 0,08 | 1 при совпадении, иначе 0; только если заполнена у обоих |

Это не фиксированные проценты. У «Новокаина» нет франшизы: её коэффициент исключается, знаменатель при остальных заполненных полях равен **0,95**. Если у сравниваемого фильма нет года, длительности или публичного рейтинга, их коэффициенты тоже исключаются. Пустые жанры/актёры/режиссёры/описание дают нулевое сходство, но соответствующие коэффициенты остаются в знаменателе.

Для описаний текст переводится в нижний регистр, ё заменяется на е, знаки удаляются. Убираются встроенные стоп-слова, слова короче трёх символов и целые числа. Затем:

```text
idf слова = ln((N + 1) / (число описаний с этим словом + 1)) + 1
вес слова = (1 + ln(число повторов слова)) × idf
```

Вектор нормируется, после чего считается косинус между векторами. Скрипт сопоставляет слова, а не понимает сюжет. Формы слов не приводятся к общей основе. Английские и русские названия жанров не переводятся друг в друга: Action и «Боевик» — разные значения, если они так записаны в базе.

## 5. Поправка по 55 соседям

Сходство меньше 0,055 отбрасывается. Выбираются максимум 55 самых похожих карточек. Здесь их **55**, диапазон похожести — **0,357223…0,416575**.

```text
Остаток соседа = твоя оценка соседа − его базовый прогноз
Вес соседа = похожесть³
Доля соседа = его вес / сумма весов 55 соседей
Вклад соседа = доля × остаток
Поправка похожих = сумма 55 вкладов
```

Так модель учитывает, насколько такие фильмы нравятся тебе сильнее или слабее общей зависимости от IMDb/КП. Это не простое среднее твоих оценок соседей.

Для «8 подруг Оушена»:

```text
Твоя оценка: 3
Его база: 5,9725408807
Остаток: −2,9725408807
Вес: 0,4165751383³ = 0,0722903024
Доля: 2,5887164936%
Вклад в прогноз «Новокаина»: −0,0769506561
```

Сильнее всего понижают прогноз: [[Кино/Media/Ненасытные люди|Ненасытные люди]] (−0,1243), [[Кино/Media/Невыносимая тяжесть огромного таланта|Невыносимая тяжесть огромного таланта]] (−0,0905), [[Кино/Media/8 подруг Оушена|8 подруг Оушена]] (−0,0770).

Сильнее всего повышают: [[Кино/Media/3 дня на убийство|3 дня на убийство]] (+0,0572), [[Кино/Media/Форсаж 8|Форсаж 8]] (+0,0529), [[Кино/Media/Захочу и соскочу - Супергерои|Захочу и соскочу - Супергерои]] (+0,0420).

Повышающие вклады: +0,6213992194. Понижающие: −0,9019874971. **Итоговая поправка похожих: −0,2805882777.**

Среди 55 соседей нет совпадений режиссёров. Общие актёры есть у двух: «Воздушное ограбление» — Jacob Batalon, «Главы государств» — Jack Quaid.

## 6. Поправка по категориям

Она считается по **всем 1553 другим оценённым карточкам**, а не только по 55 соседям. Используются жанры, десятилетие, группа длительности и франшиза. Для «Новокаина» франшизы нет, остаются три группы.

```text
Эффект значения категории = сумма остатков / (число карточек + 10)
```

Добавка 10 сглаживает маленькие группы к нулю.

| Группа | Значение | Карточек | Сумма остатков | Сглаженный эффект |
|---|---|---:|---:|---:|
| Жанры | action | 448 | +36,2024 | +0,0790 |
| Жанры | comedy | 448 | −4,5270 | −0,0099 |
| Жанры | crime | 159 | −2,6452 | −0,0157 |
| 2020-е | 2020s | 221 | −193,4078 | −0,8373 |
| 90–129 минут | medium | 954 | +20,7482 | +0,0215 |

Три жанра сначала усредняются внутри группы. Затем усредняются три группы с равным весом:

```text
Жанры = (+0,0790444884 − 0,0098843682 − 0,0156522934) / 3
      = +0,0178359423
2020-е = −0,8372633964
90–129 минут = +0,0215230252

Общая категория = (+0,0178359423 − 0,8372633964 + 0,0215230252) / 3
                = −0,2659681430
В итог входит 75% этой величины:
0,75 × −0,2659681430 = −0,1994761072
```

Главный эффект здесь — десятилетие: по 221 другой карточке 2020-х твои оценки оказались ниже их базовых прогнозов. Жанры и длительность слегка повышают результат.

## 7. Итог и запись

```text
База                         5,9197586817
Поправка 55 похожих          −0,2805882777
75% поправки категорий       −0,1994761072
───────────────────────────────────────
Итого                        5,4396942968
После округления             5,4
```

Результат ограничивается диапазоном 1…10, округляется до десятых и записывается строкой «5.4» в «Прогноз оценки». Личная «Оценка: 6» остаётся отдельным значением. Разница с округлённым прогнозом — +0,6 балла.

Внутри также вычисляется условная уверенность: clamp(55 / 35 × 0,5 + средняя похожесть первых 10 × 0,7, 0, 1). Здесь она равна 1. Это эвристика количества и близости соседей, а не вероятность точного попадания. Сейчас интерфейс её не показывает.

## 8. Когда выполняется расчёт

- При создании карточки — после записи данных, файла ролей и обработки франшизы.
- Команда «Кино - Обновить оценки» из карточки пересчитывает её прогноз; из «Проверки кинотеки» — всю коллекцию.
- Открытие заметки показывает сохранённое поле. Добавление новой оценки само по себе не переписывает старые прогнозы.
- Следующий пересчёт может измениться при правках других твоих оценок или признаков карточек.

## 9. Как проверен этот разбор

Тот же predict_rating.js исполнен с диагностической веткой в копии кода в памяти. Прочитаны реальные YAML-поля основных карточек и файлов ролей. Одиночный и пакетный запуск исходной функции дали **5,4**. Запись одиночного запуска перехвачена и не дошла до диска.

Проверены суммы 55 вкладов, частей похожести и категорий. Они совпадают с внутренними величинами исходной модели.

Сохранённое поле 5,4 не хранит историю коэффициентов и соседей. Этот разбор воспроизводит **текущее** вычисление, давшее то же округлённое число.
