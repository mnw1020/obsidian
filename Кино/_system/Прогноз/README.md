# Прогноз личной оценки

Система состоит из двух слоёв.

1. **Локальная интерполяция** - работает сразу и не требует интернета. При каждом запуске заново читает все текущие карточки в `Кино/`, поэтому фильмы и оценки, добавленные позже, учитываются автоматически. Использует жанры, режиссёров, актёров из файлов ролей, описание, тип (фильм/сериал), франшизу, год, длительность, IMDb/КП оценки и их доступность.
2. **MovieLens** - необязательный коллаборативный слой в духе Имхонета. Использует оценки пользователей со схожим вкусом. Если конкретного фильма в MovieLens нет, прогноз автоматически остаётся на локальной интерполяции.

## QuickAdd

Создать User Script / Macro с именем, например, `Кино - Прогноз оценки` и выбрать:

`Кино/_system/predict_rating.js`

Открыть карточку фильма и запустить команду. Скрипт НЕ меняет поле `Оценка`. Он записывает отдельные поля:

- `Прогноз оценки`
- `Прогноз уверенность`
- `Прогноз метод`
- `Прогноз локальный`
- `Прогноз MovieLens` - только когда доступны коллаборативные данные

## Подключение MovieLens

Один раз запустить:

`Кино/_system/Обновить модель MovieLens.bat`

или вручную:

`python Кино/_system/build_movielens_model.py`

Скрипт скачивает MovieLens 32M с GroupLens и создаёт:

`Кино/_system/Прогноз/movielens_neighbors.json`

После этого `predict_rating.js` автоматически начинает использовать MovieLens. При накоплении большого числа новых личных оценок модель соседей можно перестроить тем же BAT-файлом. Даже без перестройки текущая схожесть с сохранёнными кандидатами пересчитывается на каждом прогнозе.

## Что происходит с новыми фильмами

Новые `.md` в корне `Кино/` подхватываются автоматически. Если у нового фильма есть IMDb ID и он есть в MovieLens, используется гибридный прогноз. Если MovieLens его не знает (например, новый релиз), используется локальная интерполяция по всей доступной информации карточки.

## Автопрогноз при добавлении фильма

В этой версии `Кино/_system/Examples_Attachments_movies.js` после создания карточки автоматически запускает `Кино/_system/predict_rating.js` для только что добавленного фильма/сериала. Отдельно открывать карточку и запускать команду прогноза не нужно.

Если фильм есть в MovieLens, используется MovieLens + локальная интерполяция. Если его там нет, прогноз всё равно рассчитывается по локальной интерполяции твоей кинотеки.

## Колонки в базе

В `Кино/_Кино.base` добавлены `Прогноз`, `Прогноз локальный` и `Прогноз MovieLens`. В виде `Сравнение оценок` также есть:

- `Δ к прогнозу` = `Моя оценка - Прогноз`;
- `Δ к локальному` = `Моя оценка - Прогноз локальный`;
- `Δ к MovieLens` = `Моя оценка - Прогноз MovieLens`.

Положительная дельта означает, что реальная оценка оказалась выше прогноза, отрицательная - ниже. Колонка актёров из видов базы убрана.
