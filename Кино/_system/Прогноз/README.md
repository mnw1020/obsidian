# Прогноз и рекомендации

Прогноз рассчитывается локально скриптами `predict_rating.js` и `predict_all_ratings.js` по личным оценкам и метаданным карточек. Записывается только `Прогноз оценки`. При добавлении фильма расчёт запускается автоматически после обработки франшизы.

Эта папка хранит выбранную карточку и кэши рекомендаций. Рекомендации используют локальную базу, Кинопоиск и TMDB; IMDb доступен ссылкой.
