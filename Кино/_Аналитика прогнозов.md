> **Δ = Моя оценка − Прогноз.** Положительное значение означает, что фильм понравился сильнее прогноза; отрицательное — слабее. Все расчёты обновляются автоматически из YAML карточек при открытии заметки.

function stats(arr, key) {
    const vals = arr
        .filter(r => r[key] !== null)
        .map(r => ({...r, err: r.actual - r[key], abs: Math.abs(r.actual - r[key])}));

## Что означают показатели

- **MAE** - средняя абсолютная ошибка в баллах. Например, MAE `1.2` означает, что прогноз в среднем отличается от твоей оценки на 1.2 балла.
- **RMSE** - сильнее штрафует крупные промахи. Чем меньше, тем лучше.
- **Δ среднее** - систематическое смещение: `+` означает, что модель обычно занижает твою оценку; `-` - завышает.
- **±0.5 / ±1.0** - доля прогнозов, попавших в указанный диапазон от твоей реальной оценки.
